# 建築会社サイトの静的コーディング
## 概要
デザインカンプをもとに、建築会社サイトの静的コーディングを実装しました
## 実装内容
静的ページ構築：main/company/access/contact  
レスポンシブ対応（PC/タブレット/スマートフォン）  
JavaScript: humberger, form, modal, Slider. 
## 工夫した点
* レスポンシブ対応のため、サイズ指定にvwや%を活用
* 各ページのサイズ感を統一するため、div要素で囲って位置を配置
* 同じデザインの要素はHTMLでの名前付けを統一
## 苦労した点
* 後から見返したときにわかりやすいHTMLの名前付けを考えること
